== Read This As

* AI is for image and video generation.
* Audio is for timing, cueing, and signal control.
* Code is for procedural logic and generative visuals.
* Hardware is for physical interaction and installation control.
* TouchDesigner is the central hub where everything can converge.

== Notes

* Strudel and p5.js share JavaScript roots.
* Ableton, Max/MSP, and OSC form the control layer.
* AI output can branch into TouchDesigner, After Effects, or export pipelines.
* The same system can end in projection, VJ playback, installation, or archived video.
